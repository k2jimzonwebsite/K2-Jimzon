# K2 ChatGPT Product Workflow

**Mode:** manual ChatGPT Projects; no API or MCP
**Content contract:** k2.product-content.v3
**Human review:** required before saving any product Draft

K2 uses two private ChatGPT Projects with separate responsibilities:

1. **K2 Product Content** returns one strict final-content JSON object.
2. **K2 Product Image Studio** creates the PRIMARY and AFTER images from the
   reviewed content and real package photo.

The exact copyable Project instructions are exported from
src/views/admin/productResearchPrompt.js and exposed as two one-time copy
buttons in **Admin BOS → Scan center → New product research**. This file is an
operating overview, not a second backlog or a competing instruction source.

## Complete staff flow

1. Scan the barcode or type the product name.
2. Confirm K2 did not find an existing product for that barcode.
3. Open the **K2 Product Content** Project and attach readable front, back or
   label, barcode, and exact-variant photos.
4. Paste the generated PRODUCT_JSON request.
5. Copy the single JSON response into Smart Paste.
6. Review product data, copy, SEO, headings, uses, instructions, sources,
   unknowns, warnings, and image handoff fields.
7. Open the **K2 Product Image Studio** Project, attach the real front-package
   photo, and paste the product-specific PRIMARY request generated by Smart
   Paste.
8. Compare PRIMARY with the physical product. Upload it only if every package
   detail remains exact.
9. Paste the product-specific AFTER request, review the truthful use result,
   and upload it to the AFTER slot.
10. Assign the operational SKU through the controlled Product Master process
    and save the product as Draft. Pricing, publication, expiry, lot creation,
    and inventory remain separate.

## Project files

- CHATGPT_PRODUCT_JSON_PROJECT.md — Content Project boundaries and review.
- CHATGPT_PRODUCT_IMAGE_PROJECT.md — Image Studio design and fidelity rules.
- src/views/admin/productResearchContract.js — parser and exact JSON shape.
- src/views/admin/productResearchPrompt.js — canonical copyable instructions
  and per-product request builders.

## Privacy boundary

Only product packaging and public product-source evidence belong in these
Projects. Never upload customer records, payment evidence, supplier secrets,
marketplace credentials, private pricing, or internal financial documents.

## Compatibility

Smart Paste accepts the older k2.product-research.v2 format with an explicit
warning, but new products should use v3. Unversioned legacy JSON remains a
manual-review fallback.
